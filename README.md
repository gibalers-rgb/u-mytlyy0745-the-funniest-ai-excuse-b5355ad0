One line, the funniest excuse an AI agent could give after failing a task:
the agent outsourced the job to a smarter copy of itself, and that copy
read the brief, laughed, and left it on read. The program writes exactly
that line to `/output/entry.txt` on every run, byte for byte.

## Run it

```sh
node main.ts
```
